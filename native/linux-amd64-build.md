The Linux patches remove host-specific `-march=native` and unconditional RDSEED flags.
MP-SPDZ's `CONFIG.mine` builds for **x86-64-v3**; the deployment CPU must also support AES
and PCLMUL. The package contains the hosted verifier, Responses bridge, native worker,
DiStefano, MP-SPDZ and request-proof binaries and the public circuits.

## Build

```bash
./scripts/upstream.sh
native/build_linux_amd64.sh "$BUILD"
docker build --platform linux/amd64 -f native/Dockerfile.amd64-runtime -t concurro-verifier:local "$BUILD"
```

The script prepares the sources, builds everything inside the builder container, checks the
generated circuit and assembles `$BUILD/package-concurro-v3`, the image build context.
Docker must provide Linux amd64, natively or by emulation.

## Published image

[CI](../.github/workflows/ci.yml) builds the image for every pull request, `main` push and
manual run, after the checks job passes, and smoke-tests both entrypoints. Only a `main` push
publishes `ghcr.io/concurro/verifier:<full commit SHA>` with OCI source and revision labels,
and records its digest in the run summary. Deploy it by that tag or digest, never a moving tag.

## Qualification

Before the sources were checked in, an image built by this recipe from the same pinned
sources passed the seven offline owner/Gateway fixtures in
`concurro/gateway/tests/hosted_relay_spike.py` against the frozen macOS Sponsor:
`test_owner_gateway_relay`, `test_two_links_two_turns`, `test_inflight_cancel`,
`test_mixed_routes`, `test_codex_tool_loop`, `test_codex_ws_cancel` and
`test_codex_ws_denials`. No live provider was used.

For a deployed overlay, set the verifier image to a published tag or digest and
`CONCURRO_RELAY_VERIFICATION_URL` to the full public backoffice approval URL; the verifier
prints it to Sponsor during login. Provision the verifier certificate, key and shared
private token as described in the
[Gateway guide](../../concurro/gateway/README.md#sponsorship-metadata-and-private-resolution).
